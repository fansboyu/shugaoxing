# standard-static-v1.1 模板接入规范

统一内容接口，不统一客户视觉。导入、绑定、保存不影响线上，发布才生效。

## 必须交付

- 完整静态页面与资源；publisher.config.json 声明首页、列表、详情、卡片、输出路径、资源目录、卡片占位符。
- 文件必须存在，路径必须为包内相对路径，不允许软链接、越级、服务器程序、凭据和运行数据。
- 声明协议及 requiredCapabilities，主控必须显式检查支持情况，而非忽略未知能力。
- 每个完整 HTML 页面及文章详情模板必须包含电话字段和页脚备案字段。

| 字段 | 来源/规则 |
| --- | --- |
| contact_phone | 网站 phone，必填，规范化为可选国际前缀加 5–20 位数字 |
| contact_phone_url | 构建器派生 tel: 加规范化号码，不能接受任意协议 |
| icp_number | 网站内容字段，完整备案号，运营核对真实性 |
| icp_url | 网站内容字段，仅允许 https://beian.miit.gov.cn/ |

文本/属性按 HTML 上下文转义。本模板电话也进入 JSON-LD，因此必须先校验上述号码格式。
任意字符串进入 JSON-LD 需 JSON 转义并防止 script 闭合；正文由主控安全清洗。
不要把文章历史正文中的号码自动替换成联系电话。

## 文章约定

首页、列表放 article_cards；详情必须包含 content_html，资源及导航通过
asset_prefix、home_url、news_index_url 输出正确相对地址。
模板保留原有静态页面。当前生成路径为 news/<文章编号>/index.html。
已有文章迁移需保留 URL 或制定重定向映射，禁止静默覆盖同路径固定页。
主控当前分类未接通，本模板直接使用“行业洞察”栏目文字。

## 发布验收

- 固定模板版本 + 数据库内容快照构建完整静态站。默认资料只用于首次确认，不自动覆盖现有数据。
- 每页电话/备案正确，无残留占位符，无断链，JSON-LD 可解析，原页面和资源保留。
- 产物不包含模板详情源文件、初始化资料、脚本测试、文档或密钥。
- Agent 校验切换，失败保留旧站；回滚恢复整个旧版本，包括旧电话/备案值。

## 主控仍需开发

官网备案字段表单/API/快照/构建支持（可存现有 sites.content JSONB）、能力校验、
ZIP 上传和校验报告、文章输出路径冲突保护、首页条数和列表分页。
修改此模板不会自动实现这些平台功能。
